# ⚔️ Calabozos y Fracciones — Pixel Game Feel Edition

Videojuego educativo RPG en Pixel Art donde resuelves fracciones (propias, impropias, sumas y restas homogéneas) para derrotar monstruos, abrir cofres de botín, equipar ítems RPG y conquistar mazmorras.

## 🎮 Características
- **4 Modos de Juego:** Modo Aventura (2 mazmorras), Modo Desafíos (4 misiones especiales), Modo Infinito (oleadas con recompensas x2 y récord local) y Tutorial.
- **14 Monstruos Pixel Art Personalizados** con animaciones propias (desde el *Goblin Perezoso* y *El Pícaro* hasta el *Rey "Panza"* y *Rogelio, Clan Psitacus*).
- **6 Sistemas de Game Feel:** Hit Feedback, Taking Damage, Jump & Land, Chest Open, Coin Pickup y Victory.
- **Escenarios Pixel Art Animados:** Calabozo de piedra con antorchas y Bosque Encantado con luna y luciérnagas.

## 🧪 Extra
- [Game Feel FX Studio](game_feel_studio.html): Sandbox interactivo para probar todos los efectos visuales de forma independiente.
